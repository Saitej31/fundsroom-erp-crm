# Mini ERP + CRM Operations Portal

A full-stack ERP and CRM operations portal built to manage business workflows, customer information, and operational activities in one centralized application.

## 🚀 Features

- ERP operations management
- CRM functionality
- Customer management
- Business workflow management
- Frontend and backend separation
- Organized and scalable project structure

## 🛠️ Tech Stack

- TypeScript
- JavaScript
- HTML
- CSS
- Python
- Flask
- Database
